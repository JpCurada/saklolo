# LinkButton

A link styled as a Button, for navigation: "Open the dashboard", "View on GitHub".

**Don't use it for** actions that change data: use `Button`.

| Prop | Values | Default |
|---|---|---|
| `href` | where it goes | required |
| `variant` | `primary`, `secondary`, `ghost` | `primary` |
| `size` | `sm`, `md` | `md` |
| `external` | opens in a new tab | off |
| `testId` | `data-testid` | none |
