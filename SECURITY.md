# Security

Please report vulnerabilities through
[GitHub's private reporting](https://github.com/JpCurada/saklolo/security/advisories/new),
not a public issue.

Saklolo is a hackathon project and isn't ready for real rescue data. The demo API has
no sign-in, so anyone who can reach it can read cases and act on them. Run it locally,
or with synthetic data only.

In a real emergency in the Philippines, call 911.
